# Geometry Assist for Autodesk Fusion

**Validated baseline:** v0.14.14. Geometry Assist is a Python add-in for Autodesk Fusion, providing inferred geometry selection, assisted fillet/chamfer and direct-edit workflows, history-independent feature recognition, and native feature reconstruction on imported/history-free B-Rep solids.

The complete installable add-in is [`GeometryAssist/`](GeometryAssist/), including the manifest, Python source, settings, and all Resources SVG icons. Install or clone **that entire folder** into your Fusion add-ins directory, then load it in **Scripts and Add-Ins**. This repository does not bundle Autodesk's `adsk` runtime; supported feature creation requires Fusion.

## Current reconstruction boundary

The v0.14.14 reference case is an exterior-open **Ø25 mm cylindrical cut** intersected by **four partial Ø4 mm cylindrical cuts** in a roughly **5 mm** plate. Interactive Fusion testing confirmed geometry-preserving, editable native reconstruction of that particular STEP case. This is **not** a blanket guarantee for mirrored, rotated, changed-thickness, changed-count, or more complicated groups.

The add-in restores analytic cut stock on an independent preserved-body copy and creates native Cut Extrude or New Body + Combine/Cut features for this intersected group; supported standalone holes continue through their native HoleFeature route. Source-body preservation, geometry equivalence, and rollback checks remain mandatory. The tested tool-side-bridge approach should not be rewritten before broader regression evidence exists.

Run the offline package checks (Python 3.10+):

```bash
python -m unittest discover -s tests -p 'test_*.py' -v
```

GitHub Actions runs these checks on supported Python versions. They inspect package completeness, Fusion manifest/version, syntax, default-settings compatibility, toolbar resources, command identifiers, and rebuild/rollback source interfaces. **They do not execute Fusion geometry or UI workflows.** Manual PASS status is tracked separately in the regression matrix.

Do not commit private user STEP models, diagnostic logs, or generated bytecode unless they have been reviewed for distribution.
