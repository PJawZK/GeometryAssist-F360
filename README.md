# Geometry Assist for Autodesk Fusion

Geometry Assist is an Autodesk Fusion add-in for inferred geometry selection, assisted fillet/chamfer/direct-edit workflows, history-independent feature recognition, and native feature reconstruction on imported/history-free B-Rep solids.

Current validated baseline: **v0.14.14**.

The installable add-in lives in [`GeometryAssist/`](GeometryAssist/). Copy or clone that folder into Fusion’s AddIns directory and load it from Scripts and Add-Ins.

See [`GeometryAssist/README.md`](GeometryAssist/README.md) for feature notes and version history.
